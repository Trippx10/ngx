# Портфолио — как пользоваться

Откройте `index.html` в браузере (двойной клик). Копии сайтов лежат внутри `portfolio/projects/` — так кнопки «Посмотреть сайт» и «Живое превью» работают во всех браузерах, включая Safari (он не открывает локальные файлы из папок выше). Если правите исходный сайт, скопируйте изменения и в `projects/`.

## Что где менять

Всё редактируемое — в **`js/config.js`**:

- `name`, `role`, `year` — имя/название студии в логотипе и подвале.
- `contacts` — почта и Telegram (сейчас заглушки `hello@example.com` и `t.me/username`).
- `socials` — ссылки в меню и подвале.
- `tech` — список технологий (`main` — крупно, `extra` — «также в проектах»).
- `projects[].url` — **ссылка на реальный сайт проекта**. Сейчас ведёт на копии в `projects/`. После публикации вставьте адрес вида `https://...`.
- `projects[].previewUrl` — отдельный адрес для живого превью (если пусто — берётся `url`).
- `projects[].livePreview` — `false`, если сайт запрещает показ во фрейме.
- Тексты кейса: `short`, `task`, `features`, `stack`, `note`.

У «Жаровни» `url` пустой: меню загружается с сервера, поэтому без запущенного backend страница показывает ошибку загрузки. Когда будет постоянный адрес — впишите его в `url`, и кнопка «Посмотреть сайт» станет активной.

## Картинки

Превью в `assets/` сняты автоматически со страниц проектов. Шрифты Dela Gothic One, Onest и Unbounded при съёмке были заменены похожими, поэтому на скриншотах барбершопа и «Жаровни» типографика немного отличается от оригинала. Чтобы заменить превью, сохраните свой скриншот с тем же именем файла (1440×900 для desktop, 390×844 для mobile, формат webp/jpg/png) или поменяйте путь в `config.js`.

## Публикация

Загрузите на хостинг (Netlify, Vercel, GitHub Pages) папку `portfolio` целиком — проекты уже внутри. Или замените `url` на уже опубликованные адреса.

Цвет акцента — переменная `--accent` в начале `css/style.css`.
