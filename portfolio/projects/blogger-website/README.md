# ALEX. — персональный сайт блогера

Учебный проект на HTML5, CSS3 и JavaScript, без сборки, библиотек и сервера. Alex Morgan, публикации и показатели вымышлены. Форма показывает подтверждение, но не отправляет и не сохраняет данные. Социальные ссылки ведут на главные страницы платформ.

## 1. Как запустить
Откройте `index.html` двойным щелчком в браузере. Интернет не требуется: фотографии находятся в проекте. Для разработки также можно использовать расширение Live Server в VS Code.

## 2. Где менять фотографии
Замените файлы в `images`, сохранив имена, либо измените `src` у тегов `<img>` в `index.html`. Обновите описания `alt`. Портрет: `alex.jpg`; публикации: `tokyo.jpg`, `setup.jpg`, `travel.jpg`, `istanbul.jpg`, `backpack.jpg`, `offline.jpg`. Для иной обрезки измените `object-position` в CSS.

Демонстрационные фотографии загружены с Unsplash. Портрет — иллюстрация вымышленного персонажа, не утверждение о личности изображённого человека. Источники: https://images.unsplash.com/photo-1506794778202-cad84cf45f1d (портрет), photo-1540959733332-eab4deabeeaf (Токио), photo-1498050108023-c5249f4df085 (сетап), photo-1464822759023-fed622ff2c3b (горы), photo-1524231757912-21f4fe3a7200 (Стамбул), photo-1553062407-98eeb64c6a62 (рюкзак), photo-1441974231531-c6227db76b6e (лес). Все идентификаторы используют тот же адрес images.unsplash.com.

## 3. Где менять тексты и оформление
Все тексты — в `index.html`, основные секции отмечены комментариями. Содержимое карточек раскрывается через стандартный HTML-элемент `details`. Сообщение формы — в `script.js`. Цвета находятся в переменных `:root` в начале `style.css`; адаптивные правила — в конце файла.

## 4. Где менять социальные ссылки
В `index.html` замените `href` у ссылок в `.hero-socials`, `.social-grid` и в подвале `.footer`. Для каждой сети укажите один и тот же адрес профиля во всех местах. Ссылки открываются в новой вкладке.
