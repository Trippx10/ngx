# Сайт барбершопа «name» — версия для компьютера

Чистые HTML, CSS и JavaScript, без библиотек и сборки.

## Как запустить
Открой `index.html` в браузере или загрузи папку целиком на хостинг (GitHub Pages, Netlify, Vercel, обычный веб-сервер).

## Структура
- `index.html` — разметка страницы
- `css/style.css` — стили
- `js/main.js` — маскот Чубик, анимации, мини-игра, галерея «до / после», слайдер отзывов, карта, форма записи

## Что есть в версии для ПК
- Боковая навигация по разделам справа, по ней едет Чубик.
- Прайс в две колонки: слева заголовок и кнопка записи закреплены, справа список; клик по строке открывает запись на эту услугу.
- Галерея из 5 работ с ползунком «до / после» прямо на странице.
- Горячие клавиши: З — запись, И — мини-игра, Esc — закрыть окно.
- Ближайшее свободное окно на первом экране, мастера в один ряд с наклоном за курсором.

## Что заменить перед запуском
- Название «name», адрес, телефон, почту, соцсети, ссылку «Показать маршрут».
- Прайс (блок `#price` в `index.html`) и список услуг формы (`SVC` в `js/main.js`).
- Мастеров (`TEAM`), работы (`WORKS`), отзывы (`REVIEWS`), часы работы (`HOURS`) в `js/main.js`.
- Отправку заявки: функция `sendBooking()` в `js/main.js` пока только имитирует отправку. Подключи свой API или CRM.
