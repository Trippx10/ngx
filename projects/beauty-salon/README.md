# LUMI Beauty Studio

Адаптивный одностраничный учебный сайт на HTML5, CSS3 и обычном JavaScript. Без сборки, библиотек, базы данных и сервера приложений.

## Файлы

- `index.html` — структура страницы, тексты, услуги, цены и контакты.
- `style.css` — палитра, сетки, оформление, адаптивность и анимации.
- `script.js` — мобильное меню, проверка формы и появление блоков.
- `images/` — локальные фотографии интерьера и трёх мастеров.
- `PHOTO-CREDITS.md` — источники фотографий.

## Запуск

Распакуйте весь проект и откройте `index.html` в браузере двойным щелчком. Установка зависимостей не нужна. Для удобного редактирования можно открыть папку в VS Code и использовать расширение Live Server.

## Что менять

- **Тексты и цены:** в `index.html`. Карточки услуг находятся внутри `#services`. При добавлении услуги также обновите список `<select id="service">` в форме.
- **Фотографии:** замените `images/salon.jpg`, `anna.jpg`, `maria.jpg`, `sofia.jpg` своими файлами. Если меняете имена, обновите `src` у соответствующих `<img>` и их описания `alt`. Для интерьера и портретов подходят вертикальные снимки.
- **Цвета:** переменные в блоке `:root` в начале `style.css`.
- **Адаптивность:** блоки `@media` в конце `style.css`.
- **Поведение формы:** обработчик `submit` в `script.js`.
- **Контакты:** секция `#contacts`. Замените адрес, телефон, `tel:` и ссылки на реальные профили. Telegram и Instagram сейчас ведут на главные страницы сервисов. «Показать на карте» раскрывает пояснение о вымышленном адресе; для реального салона замените `<details>` ссылкой на карту.

## Важно для демонстрации

Салон, имена, отзывы, показатели и контакты вымышлены. Фотографии — иллюстрации, а не реальные сотрудники. Форма проверяет имя, телефон (10–15 цифр) и выбранную услугу. При успехе показывает сообщение без отправки или сохранения данных. Реальной записи не происходит.

Плавная прокрутка работает через CSS, ссылки доступны без JavaScript. Анимации учитывают настройку уменьшения движения. Для реального приёма заявок потребуется отдельно подключить обработчик отправки.
